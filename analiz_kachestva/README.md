# Анализатор качества информации (рейтинг A/B/C/D)

**Зачем:** перед тем как материал (пост, разбор, статья, отклик hh, «наработка») попадёт в работу — быстро и локально понять, стоит ли он доверия. Никаких LLM API, только stdlib: регэкспы, словари маркеров, арифметика. Работает сразу, на любой машине с Python 3.x.

## Модель оценки (5 критериев × 0–20 = 0–100)

| Критерий | Что смотрит | Шкала |
|---|---|---|
| **Доказательность** | числа с % и ₽/$, «по данным/N=», ссылки `[..](..)` и bare URL; «говорят/очевидно» без источника — штраф | 0–20 |
| **Конкретность** | плотность цифр на 100 слов, примеры/кейсы; вода («в современном мире», «играет ключевую роль», «уникальный»…) — штраф за каждое | 0–20 |
| **Свежесть** | возраст самой новой даты: <1 года = 20, до 3 лет = 12, до 7 = 6, старше/без дат = 3 | 0–20 |
| **Согласованность структуры** | заголовки, списки, абзацы <2000 симв., выводы/резюме | 0–20 |
| **ИИ-шаблонность (инверсия)** | «важно отметить», «стоит подчеркнуть», «подводя итог», «давайте рассмотрим» — чем больше штампов, тем ниже балл (эхо skill `ai-detector`) | 0–20 |

**Рейтинг:** A ≥80 · B 60–79 · C 40–59 · D <40.

## Как пользоваться

```bat
:: анализ файла (отчёт в консоли + JSON в reports\<имя>_анализ.json)
python analyz.py путь\к\файлу.md

:: демо на трёх встроенных текстах (A-образный / C-образный / D-образный)
python analyz.py --demo

:: вставка текста потоком
type статья.txt | python analyz.py
```

JSON-отчёт: `{рейтинг, сумма, breakdown × 5, топ-3 проблемы, найденные даты, найденные ссылки, статистика}`. В логи (`D:\Логи\analiz_kachestva\analizator\`) пишутся только длина, хэш и вердикт — **сам текст документов туда не попадает**.

## Встраивание в HH-монитор (import)

```python
import io, sys
sys.path.insert(0, r"C:\Users\Илья\Documents\ilya-claude\projects\analiz_kachestva")
from analyz import analyze, rate

res = analyze(текст_вакансии_или_отклика)   # -> dict
if res["рейтинг"] in ("A", "B"):
    show(вакансия)          # показываем Илье только качественное
else:
    log("отброшено D", res["сумма"])

# порог настраивается вручную: например, показывать при сумме >= 50
```

Возможные места применения: фильтр описаний вакансий hh перед показом, проверка статей/исследований перед занесением в БЗ (`D:\Наш RAG`), приёмка текстов от подрядчиков-копирайтеров.
