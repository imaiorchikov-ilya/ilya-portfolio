## 🗂 Кейсы

### 1. Акт-конвейер — бот, который списывает материалы сам
- **Что делает:** присылаешь в Telegram-бот выгрузку ОСВ по 10 счёту и ресурсные ведомости 1С → получаешь готовый акт списания материалов М-11 в Excel, посимвольно сверенный со складом.
- **Метрика:** день ручной работы → **20 минут**. Два боевых контракта, формат подтверждён бухгалтером клиента.
- **Стек:** Python (openpyxl/xlrd), Telegram Bot API, генератор документов с эталонной сверкой ОСВ↔ведомости, белый список папок для файловых операций.

### 2. Вектор колибри — умная база знаний без галлюцинаций
- **Что делает:** корпоративная база знаний: вопрос по документам компании → ответ с точной цитатой и источником; если данных нет — честно отвечает «в базе нет» (контроль галлюцинаций eval-скриптом).
- **Метрика:** eval-набор **14/14 PASS** (правильный чанк по BM25-поиску + честный отказ на негативах).
- **Стек:** BM25-индекс локально (кэш текстов, автоиндексация), LLM-слой на локальном Ollama, OCR для сканов (tesseract rus+eng), PyMuPDF/pdfplumber.

### 3. Jarvis — голосовой AI-ассистент (MVP продакшен-класса)
- **Что делает:** голосовые сообщения → Whisper large-v3 локально → команды: документы, память, конвейеры. Интерфейсы: Telegram + clipboard.
- **Метрика:** **86 автотестов зелёных**; модульная архитектура (orchestrator, brain, vision-router).
- **Стек:** faster-whisper (CPU int8), Telegram Bot API, vision-роутер с правилом «замаскировано → бесплатная/платная модель».

### 4. Маскирование ПДн (redactor) — 152-ФЗ как первый класс гражданина
- **Что делает:** перед любой отправкой файла в облачную LLM — автоматическое маскирование ПДн: телефон, email, ИНН, ОГРН, БИК, реквизиты, СНИЛС, паспорт, ФИО (текст/CSV/Excel/PDF/фото). Не смог замаскировать — файл уходит в карантин с уведомлением, а не в облако.
- **Метрика:** **18/18 тестов**; 3 уровня защиты (regex 14 паттернов → NER/FIO-fallback → retry-цикл).
- **Стек:** Python: pytesseract, openpyxl, pdfplumber, Pillow; роутинг моделей по статусу маскировки.

### 5. Мультиагентный контур (пилот)
- **Что делает:** каркас «планировщик → исполнители с инструментами → ревизор» на LangChain 1.0 + LangGraph: инструменты с регэксп-фильтрами и белыми списками, middleware маскирования ПДн, модель пинована на локальный Ollama, трейсы всех шагов в JSONL.
- **Зачем:** репетиция клиентских агентных систем с проверкой каждого шага и без утечек.
- **Стек:** LangChain Agents 1.0, LangGraph StateGraph, CrewAI (генератор субзадач → исполнители → ревизор с трассировкой), LiteLLM-гейтвей на 4000 (фейловер между локальными моделями).

### 6. Конвейер транскрибации и знаний
- **Что делает:** локальная дословная транскрибация видео/аудио любой длины (тестировалось на 6-часовых партиях), складывание в базу знаний с мгновенным BM25-поиском по всей базе.
- **Метрика:** ~5,9 ч видео → дословные транскрипты за одну ночную сессию на слабом CPU; поиск по 530+ документам < секунды.
- **Стек:** faster-whisper large-v3, ffmpeg, собственный индексатор.

### 7. Досье за минуту — подготовка к продажному звонку по одному URL
- **Что делает:** мультиагентный конвейер разбирает сайт компании: чем зарабатывает, какие проверяемые гипотезы боли, кто руководит, точка входа для продажи автоматизации. Второй инструмент — профильный URL-конвейер (4 режима: реклама / досье / отклик под вакансию / аудит сайта → КП).
- **Метрика:** полное досье за ~1 минуту; точность 5/6 типов фактов против эталона, собранного вручную.
- **Стек:** CrewAI/LangGraph-паттерн «генератор субпромптов → агенты-аналитики → финальный составитель», краулинг (BeautifulSoup), Ollama локально / облачная LLM — на выбор.

## Как я работаю

**Формула 99/1:** 99% рутины — собрать конвейер, разобрать документ, прогнать проверки, настроить интеграции — делает моя связка ИИ-агентов, которой я управляю. 1% остаётся человеком: понять, тот ли это вообще процесс автоматизировать, поймать ошибку в требованиях до того, как она стала багом, подписать ответственность за результат. Именно за этот 1% вы платите — и он не пустой: отраслевая экспертиза (стройка, снабжение, бухгалтерия списания, 152-ФЗ) + дисциплина внедрения.

Аудит (2–4 дня) → пилот (2–4 недели, одна задача, агент рядом с сотрудником, метрики в часах) → масштабирование → подписка поддержки.

Принципы: **минимально достаточное решение** («здесь ИИ не нужен» — и это тоже ответ), данные клиента не покидают локальный контур без обезличивания, опасные операции (удаление, платёж, отправка) — только через подтверждение человека.
