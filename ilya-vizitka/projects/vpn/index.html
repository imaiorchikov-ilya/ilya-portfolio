Проблема → Решение

РФ заблокировал Instagram, ChatGPT, Claude. Обычные VPN не работают.

Проблема

  • Роскомнадзор блокирует IP VPN за недели
  • WireGuard/OpenVPN видны по сигнатурам
  • Surfshark/ExpressVPN — заблокированы частично
  • Установка требует технических знаний
  • Оплата зарубежных сервисов — РФ-карты не проходят

Решение

  • VLESS+Reality маскирует под HTTPS к cloudflare.com
  • Telegram-бот = site + dashboard + support в одном
  • 1 /start → 1 оплата → 1 кнопка установки
  • Prodamus принимает РФ-карты (4% комиссии)
  • Реферальная программа 20% — виральный рост

Технический стек · обоснование выбора

8 компонентов с альтернативами

Протокол
VLESS+Reality через Xray-core. Альтернативы: Shadowsocks-2022, WireGuard+Obfs4, AmneziaWG (запасные). НЕ OpenVPN — палится по сигнатурам.
Сервер
Hetzner CX22 (Германия, 4.5 EUR/мес), Vultr, DigitalOcean. НЕ Selectel/Тимвеб — РФ-юрисдикция. 3+ сервера для отказоустойчивости.
Панель VPN
3X-UI (open-source, форк X-UI) — веб-панель управления конфигами. Альтернатива — Outline Manager (Jigsaw/Google, проще, менее гибкий).
Бот-фреймворк
aiogram 3.x — async, надёжный. Альтернативы: pyTelegramBotAPI (sync, проще, хуже под нагрузкой), grammY (TypeScript). Для MVP — aiogram.
База данных
SQLite для старта (до 1000 юзеров, 1 файл, 0 настройки). PostgreSQL при 1K+ юзеров. Redis для кэша и rate-limit.
Биллинг
Prodamus (РФ-карта, 4%) — основной. YooKassa (ФЗ-54, 2.8%) для легального ИП. Cryptomus (крипта, 1.5%) для приватных. TG Stars — дорого (30% Apple/Google).
Деплой
Docker Compose на VPS, nginx reverse-proxy, Let's Encrypt. GitHub Actions для CI/CD. Бэкап БД раз в сутки в S3-хранилище.
Мониторинг
UptimeRobot (бесплатный, проверка доступности бота и VPN-серверов). Grafana + Prometheus для метрик. Sentry для ошибок.
Конкурентный анализ

Прямые: Amnezia, BroVPN, VeePN. Косвенные: ручные продажи в ТГ

Что отличает нас: полный self-service (у конкурентов — ручная выдача), встроенная реферка 20%, семейный тариф (ниша), live-chat 5-10 мин, VLESS+Reality (у Amnezia есть, но UX слабее).

Маркетинг-стратегия · 5 каналов

От закупа в ТГ-каналах до аммбассадорской программы 30%

1. ТГ-каналы
Закуп в каналах 1K-50K подписчиков (технологии, путешествия, бизнес, крипта). 200-1000 P за пост. CAC ~200-300 P. Конверсия в тест ~3-5%.
2. Рефка
20% с подписки друга. Виральный K = 0.3-0.5 (каждый 3-й юзер приводит 1). Бесплатный месяц при 3 друзьях. Самый дешёвый канал.
3. SEO-лендинг
Простой сайт с тарифами и FAQ. По запросам «vpn telegram», «vpn для chatgpt». Органический трафик через 3-6 мес.
4. YouTube-обзоры
Тех-блогеры делают обзоры. Бартер: бесплатный год за обзор. 1 обзор = 50-200 юзеров.
5. Партнёрки
Амбассадорская программа 30% recurring. Популярные ТГ-каналы могут приносить 50-200 юзеров/мес каждый.
Риски · митигация

6 рисков — у каждого есть план Б

Роскомнадзор
VPN без лицензии — серая зона (149-ФЗ ст. 10.1). Митигация: сервер за рубежом, юрлицо не РФ, маркетинг через личные ТГ-каналы. Крупных преследуют, мелких — нет.
Блокировки IP
РКН блокирует IP VPN-серверов. Митигация: VLESS+Reality маскирует под HTTPS, 3+ сервера, авто-смена IP при блокировке, домен-фронт cloudflare.com.
Блокировка бота
ТГ могут заблокировать бота по жалобе. Митигация: несколько ботов-зеркал, резервные юзернеймы, переход на личный ТГ-канал при блокировке.
Отток клиентов
Churn 8%/мес — норма, но снижать. Митигация: реферка, скидки на продление, премиум-поддержка, новые сервера/локации как бонусы.
Конкуренция
Amnezia, BroVPN, VeePN — крупные. Митигация: нишевые тарифы (семейный), превосходящий UX, реферка, быстрая поддержка.
Оплата
РФ-карты не работают за рубежом. Митигация: Prodamus принимает РФ-карты, выплата на ИП. Крипта для тех, кто не хочет ИП.
Roadmap · 4 фазы

От MVP до B2B-tier за 12 месяцев

Фаза 1 — MVP (7-10 дней)
Бот (онбординг, /start, /status, /refer). VPS + 3X-UI. Prodamus. Тестовый запуск на 10 друзей. Цель: проверить что юзеры готовы платить.
Фаза 2 — Рост (1-2 мес)
Реферальная программа. 3 сервера. PostgreSQL вместо SQLite. Админ-бот. Реклама в 5-10 ТГ-каналах. Цель: 100 платящих юзеров.
Фаза 3 — Масштаб (3-6 мес)
Семейный тариф. 5+ серверов. Grafana-мониторинг. Амбассадорская программа 30%. SEO-лендинг. Цель: 1000 юзеров, 1.5M P/мес.
Фаза 4 — B2B (6-12 мес)
Корпоративный tier: своя панель для админа, SLA 99.9%, выделенные IP. Юрлицо для работы с компаниями. Цель: 10 B2B-клиентов.
Это SaaS?
Да. Это B2C SaaS, Telegram-first.

VPN-сервис через ТГ-бота соответствует трём признакам SaaS. При масштабировании в B2B (фаза 4) — добавляем web-панель, и это уже классический SaaS для бизнеса.

01 · ПОДПИСКА
Recurring revenue
1/3/6/12 мес, не разовая продажа. Это S в SaaS.
02 · SELF-SERVICE
Клиент сам всё делает
Регистрация, оплата, конфиг, продление. Без участия человека.
03 · MULTI-TENANT
Один код — тысячи клиентов
Общие сервера, общий бот. Multi-tenancy в инфраструктуре.
