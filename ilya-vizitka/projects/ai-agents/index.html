// технологии

RAG + evals: агент отвечает по вашим документам и проверяет себя.

Две технологии, которые отличают рабочий агент от игрушки: база знаний и автоматическая проверка качества.

RAG — база знаний

Ваши регламенты, инструкции, договоры и шаблоны превращаются в поисковый индекс. На каждый вопрос агент находит нужные фрагменты и отвечает с опорой на них.

  • Ответы по вашим документам, без фантазий
  • База обновляется без переписывания агента
  • Каждый ответ можно проверить: вот источник

Evals — контроль качества

Набор эталонных вопросов с правильными ответами. Прогоняется автоматически — качество измеряется в цифрах: точность, полнота, тон.

  • Изменение модели или промпта → прогон evals
  • Ухудшение видно сразу, до релиза
  • Абонентская поддержка включает регулярные прогоны
// процесс

Аудит → пилот → подписка.

Никаких «внедрим всё сразу». Первым идёт один измеримый успех, на нём строим остальное.

// 01

Аудит (2–4 дня)

Интервью с директором и сотрудниками. На выходе — 5–10 задач-кандидатов с оценкой часов в месяц.

// 02

Схема развёртывания

По каждой задаче — облако, гибрид или локально. Список систем для подключения.

// 03

Пилот (2–4 недели)

Одна задача, один отдел. Агент работает параллельно с сотрудником, человек проверяет всё.

// 04

Разбор пилота

Экономия ≥ 20–30% времени — масштабируем. Нет — честно меняем задачу.

// 05

Масштабирование

Новые задачи и отделы, база знаний, права доступа, обучение сотрудников.

// 06

Поддержка

Мониторинг, обновления моделей, регулярные evals, доработки. Ежемесячная подписка.

// безопасность

Красные линии, которые не нарушаются.

152-ФЗ — не пункт презентации, а условие работы. Эти правила зашиты в каждый внедрённый агент.

ПДн в облако — только через поручение на обработку по 152-ФЗ и договор с провайдером модели
Пароли, ЭЦП и платёжные ключи агенту не передаются никогда
Платёж, отправка, удаление, подпись — только подтверждением человека
Журнал действий агента: что прочитал, что создал, что отправил
Права агента — только на разрешённые папки и базы, никогда «всё сразу»
Данные клиента не используются для обучения и демо без явного разрешения
Для чувствительных данных — локальный сервер, данные не покидают контур
Не обещаем «заменит бухгалтера»: снимаем рутину на 30–60%, человек остаётся
