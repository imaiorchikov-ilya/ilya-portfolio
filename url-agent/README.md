# URL-агент — профильный конвейер по URL

*Создан 30.09.2026 (генерализация референса эксперта, реестр отложенного п.14, задача #107).*

## Что это

`url_agent.py` берёт URL → снимает главную + до 8 внутренних страниц одного домена →
запускает пайплайн «агент-генератор субпромптов → агенты-аналитики → финальный агент».
Профиль выбирает, **что именно** строим из сайта.

```
python url_agent.py <URL> --профиль {реклама|досье|вакансии|аудит_кп} --llm {ollama|proxyapi|нет} --pdf
```

## Профили

| Профиль | Что на выходе | Промтовая основа |
|---|---|---|
| **реклама** | 5-6 агентов → рекламный пост | референс эксперта (main.py / openai_module.py) |
| **досье** | досье по памятке Манье раздел 4 (зарабатывает / гипотезы боли / цифра звона / следующий шаг) | `projects/advertising/досье_компании/шаблон_досье.md` + эталон арт_ремстрой |
| **вакансии** | сопроводительное письмо под вакансию на реальном бэкграунде Ильи | данные из памяти resume-hh + `projects/hh_monitor/резюме_и_письма_А_Б_2026-09-21.md` (если файл есть — подхватывается) |
| **аудит_кп** | аудит сайта → КП по автоматизации (обследование 300 тыс. / пилот 1,5–3 млн ₽) | client-automation-playbook |

## LLM

- `--llm нет` — краулинг и каркас без модели (быстро, бесплатно).
- `--llm ollama` — локально qwen3:1.7b (CPU ~2,5 ток/с — медленно, но бесплатно и без наружки).
- `--llm proxyapi` — gpt-4o-mini через api.proxyapi.ru (ключ `PROXYAPI_KEY` в `.env`, вписывает Илья).

## Правила

- `CREWAI_TELEMETRY_OPT_OUT=1` — телеметрия наружу запрещена.
- Результат: md в `out/`, `--pdf` — через `data/tmp/md2pdf_универсальный.py`.
- Логи: `D:\Логи\url_agent\url_agent\`.
- Всё, что придумала модель помечено «?» / подлежит проверке руками — факты только из текста сайта.
- Детерминированный слой досье (телефоны/ИНН/цены/сверка) — в `projects/dosye/dosye_url.py`, этот скрипт про LLM-слой.

## Референс эксперта

`референс_эксперта/` — исходник от эксперта (Flask + OpenAI, только реклама):
`main.py` (роут), `openai_module.py` (3 шага конвейера), `Dockerfile` (паттерн для VPS-деплоя, реестр п.10).
