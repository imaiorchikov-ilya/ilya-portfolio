# Досье-автомат (`dosye_url.py`)

*30.09.2026, задача #106. Досье на компанию по памятке А. Манье, раздел 4.*

## Запуск

```
python dosye_url.py <URL> [--llm ollama|proxyapi|нет] [--pdf]
```

- `нет` (по умолчанию) — только детерминированная часть: краулинг, факты, сверка.
- `ollama` — + LLM-слой (гипотезы боли и цифра) локально qwen3:1.7b (CPU — медленно).
- `proxyapi` — тот же слой через gpt-4o-mini (ключ `PROXYAPI_KEY` в `.env` — вписывает Илья).
- `--pdf` — PDF рядом с md (через `data/tmp/md2pdf_универсальный.py`).

## Слои

1. **Краулинг:** главная + до 15 внутренних ссылок того же домена (не файлы) → тексты.
2. **Факты (regex, правда):** юрлица, title-юрлицо, телефоны (коды 3-4 цифры, форматы 3+3 и 3+2+2), emails, ИНН/КПП, ОГРН, цены (₽ и прайсовые «7 800,00»).
3. **Сверка:** юрлицо в title vs в тексте, ИНН на сайте или честное «не найден», мёртвые 404-страницы (аргумент на звонке), контакты.
4. **LLM-слой:** чем зарабатывает, 3 проверяемые гипотезы боли, цифра «на этот звонок» (обследование 300 тыс. / пилот 1,5–3 млн ₽), следующий шаг.
5. **Вывод:** `out/досье_<домен>_<дата>.md` (+ PDF), логи `D:\Логи\dosye\dosye_url\`.

## Известные границы (честно)

- Битые пункты меню краулер не видит — он ходит только по живым ссылкам с главной. Проверку «Страница 404» по прямым URL (типа /kontakty) делать руками: `curl -I`.
- Внешний слой (ЕГРЮЛ, выручка, арбитражи, банкротство, директор) — вне скоупа: агрегаторы (Т-Банк консъюмер/Xfirm/Comfex) + egrul.nalog.ru вручную перед звонком.
- LLM на локальной qwen3:1.7b — каркас черновика; для прода — proxyapi.
