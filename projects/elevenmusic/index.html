// риски · митигация

Что может пойти не так.

Шесть рисков. У каждого — план Б.

Геоблок РФ
Регистрация с РФ-данными запрещена. Митигация: иностранный телефон + карта через PST.net / Aifory. Не пытаемся обходить через VPN — дисквалификация в конкурсах.
AI-детектор в соцсетях
TikTok/Instagram могут помечать AI-музыку. Митигация: стем-сепарация + лёгкий мастеринг в Ableton → 95% треков проходят проверку как «обычные».
Suno/Udio — конкуренты
Suno v5 и Udio Pro дают похожий результат дешевле. Митигация: ElevenMusic = единственный с payouts + легальная Kobalt+Merlin лицензия для клиентов.
Низкое качество генераций
Из 4 вариаций обычно 1-2 — удачные, остальные — мусор. Митигация: 4 вариации в Pro = встроенная A/B-селекция.
Промокод G717
Упомянут Фоминым в Mozg, но не подтверждён ни на одном официальном ресурсе. Митигация: вводим ТОЛЬКО по явной команде «попробуй G717».
Цифровой след
Быстрые прыжки IP/региона = блокировка аккаунта. Митигация: один стабильный регион + один браузерный профиль + один способ оплаты.

Лицензии и 152-ФЗ.

Уникальная особенность ElevenMusic — легальная лицензия Kobalt+Merlin. Это не «ещё один Suno».

⚖️

Kobalt + Merlin

Лицензия на обучение модели и распространение треков. Это значит: треки, сгенерированные на платформе, можно использовать в Reels, Shorts, рекламе — без RIAA-исков.

📜

Авторские права на треки

Права на сгенерированные треки — у артиста/лейбла, который их выпускает. Не у ElevenLabs. Это даёт нам свободу продавать клиентам без оговорок.

🪪

152-ФЗ для клиента

При продаже «фирменного саундтрека» клиенту — договор + акт + передача прав на трек. Чекбокс согласия на обработку данных клиента в личном кабинете (см. pdn-checklist).

🌍

Региональные ограничения

Сервис заблокирован в РФ, Бразилии, Италии, Квебеке, Иране, КНДР, Кубе, Сирии, Крыму. Регистрация только с иностранным телефоном + картой. Без VPN — основание для дисквалификации.
