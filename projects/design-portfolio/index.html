// дизайн · кейс

Развёрнутые дизайн-проекты под ключ.

Полный дизайн-проект одним пайплайном: фотоколлекция эскизов всех комнат + чертёжный альбом в едином чертёжном стиле по ГОСТ 2.304-81. Альбом собирается программой — любая правка пересобирает весь альбом за минуты, а не дни ручной переклейки.

53листа альбома, единый стиль
10/10эскизов комнат приняты
1-в-1ведомость проёмов ↔ план (16 кодов)
минутыпересборка альбома после правки

// состав альбома

  • Титул → состав → планы этажей и зон (АР-05…АР-09)
  • Развёртки стен по зонам (З-01…09) с размерными цепочками в мм
  • Электро (ЭОМ) и слаботочные схемы
  • План полов, ведомости, экспликации, штампы листов N/53

// как работает конвейер

  • Эскизы: генерация опорников по комнатам + точечные правки в тех же ракурсах — консистентный вид одного и того же помещения.
  • Чертёжный слой: SVG-генерация → headless-рендер → PDF. Размерные цепочки автосверяются с геометрией (32 значения).
  • Приёмка «лист-против-листа»: каждый лист сравнивается с эталоном по рендеру и числам, не «на глаз».
  • BIM-контур на FreeCAD/Blender наращивается тем же конвейером.
